# Feature status

## Available in 0.2.0

- Single-process Rust X11 shell with system Xlib and no third-party Rust crates.
- Simple floating placement, top panel, clock text and app launch buttons.
- External terminal, file manager, browser and app launcher integration.
- Super shortcuts and nine basic in-memory workspaces.
- Source installer and X session entry.

## Not implemented

Wayland; compositor; titlebars; tiling; drag/resize; robust EWMH/ICCCM; multi-monitor/hotplug; settings; persistent configuration; wallpaper/icons; notifications; accessibility integration; session lock/logout; power, display, network, sound or Bluetooth controls; tested builds for all architectures.

“Lightweight” and “all architectures” are goals, not established benchmark or compatibility claims. The implementation is an early preview, not a complete daily-driver environment. See the repository [roadmap](https://github.com/lemonys-001/lemon-de/blob/main/docs/FEATURES.md).
