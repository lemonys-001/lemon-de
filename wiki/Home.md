# LDE — Lemon Desktop Environment

LDE is a small Rust-based X11 window manager and desktop shell. This wiki covers installing and trying the current preview. **LDE 0.1.1 is early software and is not a complete daily-driver desktop.** It supports X11 only; Wayland and many common desktop services are not implemented.
